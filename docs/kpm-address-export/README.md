# Address data for Kotor Patch Manager

Engine data mapped while building Voice of the Old Republic, exported into
KPM's AddressDatabase schema. It contains names, addresses and offsets only, with no decompiled code.
Function names are KPM's own KOTOR 1 names, so a lookup by
(class_name, function_name) resolves in both games.

## Databases

**kotor2_steam_aspyr.db / kotor2_gog_aspyr.db**
- KPM's current databases with rows added. Existing KPM rows are untouched. None of them disagreed with ours, and 6 overlapped at the same address.
- 1,107 functions added to each:
  - 166 with notes `Voice of the Old Republic: used by the mod on this build`: the addresses the mod actually calls or hooks, tested in game.
  - 941 with notes `vtable slot match ...`: K1 virtuals paired with K2 by vtable slot, only for classes with equal slot counts. Where a name appears in several vtables, the defining class's vtable decides; any split drops the name. These are strong leads, not individually verified. Filter on `notes` if you only want the first group.
  - calling_convention and param_size_bytes are copied from the K1 row.
- Steam to GOG: the GOG addresses come from the GOG exe's own RTTI vtables. As a check, 1,134 of 1,135 added functions begin with byte-identical code in both builds.
- classes: migrated to schema v5 (migration 005). The vtable column is filled from RTTI for 331 Steam / 330 GOG classes; size is left NULL. Template instantiations are omitted.

**kotor1_relink_2004.db**
- The 2004-03-05 relink of KOTOR 1 1.0.3, shipped as Allard Russian 1.72 and as LEM Polish 1.03. Both hashes are in game_version.
- It is the same compile, relinked: code is byte-identical but functions moved. .data did not move.
- offsets, classes and global_pointers are copied from kotor1_0_3.db. The mod runs on this build with exactly those globals and offsets.
- functions: the 212 we relocated (by signature scan, cross-checked against hook bytes).
- classes.vtable: the 41 we relocated; the others are NULL.

## CSV files

- **k2-functions-added.csv**: the added functions, Steam and GOG side by side.
- **k2-data-addresses.csv**: vtables and globals the mod uses (K1 / Steam / GOG), under our constant names.
- **k1-k2-vtable-slots.csv**: the full K1 to K2 slot pairing, 7,000 rows, including the `prefix` rows (classes whose slot counts differ) that were kept out of the databases.
- **k2-steam-vtables.csv / k2-gog-vtables.csv**: every RTTI vtable in each exe.
- **k1-k2-offsets.csv**: 304 struct offsets from the mod, giving the K1 value, the K2 value, and whether the two games differ, are the same, or K2 is unknown. Names are ours; class_hint and context come from our source comments, so mapping them to KPM member names needs a human pass.

## Provenance

Generated by `kpm_export.py` (included) from the mod's address tables, our
signature-scan reports and RTTI scans of the exes. Hashes:
- K2 Steam 6A522E71...BFFEF
- K2 GOG 777BEE23...3A914
- Allard 7B961A14...D7628
- LEM F96AC62B...D8137

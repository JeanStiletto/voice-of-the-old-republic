# engine_rebase.cpp (169 lines)

Implementation of engine_rebase.h. Detects the running build by reading the
PE link timestamp out of the game's own mapped image (no file I/O, safe
from a static initialiser), then binary-searches three tables in order:
the `kdev sigscan`-generated `.text` table, a hand-maintained `.rdata` table
(vtables + two data pointers — sigscan can't source-signature non-code
bytes), and a 2-entry hand-resolved cross-reference supplement for
addresses neither method could place on its own.
